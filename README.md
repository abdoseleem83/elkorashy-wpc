# ELKORASHI DOORS — طلبات أبواب WPC

تطبيق PWA لطلب أبواب WPC (القرشي)، بدون أي أدوات بناء — فتح `index.html` مباشرة كافٍ.

## بنية المشروع

| الملف/المجلد     | الوظيفة |
|---|---|
| `index.html`     | التطبيق بالكامل: HTML + CSS + JS (المصدر الرسمي الوحيد — لا يوجد ملف بناء ناتج) |
| `sw.js`          | Service Worker: الكاش والتحديث التلقائي (لازم ترفع رقم `CACHE_VERSION` مع كل ديبلوي) |
| `manifest.json`  | بيانات تثبيت الـ PWA |
| `img/`           | صور الأبواب واللوجو (منفصلة عن الكود، بتتكاش بمعرفة `sw.js`) |
| `icon-192.png`, `icon-512.png` | أيقونات التثبيت |
| `apps_script.gs` | كود الباك إند (Google Apps Script) — الصق نسخة منه في محرر Apps Script المربوط بشيت `WPC_Door_Orders_2026` عند أي تعديل، وأعد نشر الـ Web App |

## المكتبات الخارجية

المكتبات التقيلة **مش** بتتحمّل مع فتح التطبيق — بتتحمّل أول مرة تتطلب فيها بس، عن طريق
`ensureLib_()` / `needLibs_()` في `index.html`:

| المكتبة | بتستخدم في |
|---|---|
| `html2canvas` | رسم مستند الطلب/التقرير على canvas قبل تحويله PDF أو صورة |
| `jsPDF` | تحويل الـ canvas لملف PDF بصفحات A4 |
| `ExcelJS` | كل ملفات الإكسيل (التصدير العادي وتصدير المصنع) |

لو محتاج تضيف مكتبة جديدة: زوّدها في `LIB_URLS` و`LIB_READY`، وناديها بـ
`if(!await needLibs_('اسمها')) return;` قبل أي استخدام لها. المكتبات بتتخزّن في كاش منفصل
اسمه `elkorashy-libs-v1` مابيتمسحش مع تحديثات التطبيق العادية.

> ملاحظة: مكتبة `xlsx` اتشالت — كانت مكرّرة مع `ExcelJS` وبتعمل نفس الشغل.

## قواعد لازم تتراعى وانت بتعدّل

- **الرسم**: `render()` بيتجمّع في إطار رسم واحد. لو محتاج رسم فوري (زي أول تشغيل)
  نادي `renderNow()`. الفوكس ومكان المؤشر في الخانات ومكان التمرير بيترجعوا تلقائي
  بعد كل رسم — فمافيش داعي تتجنّب `render()` وانت بتكتب في خانة.
- **الأيقونات**: استخدم `ico('اسم')` من قاموس `ICONS` — مافيش إيموجي في واجهة التطبيق،
  لأن شكله بيختلف من موبايل للتاني وبيضرب الهوية البصرية.
- **الألوان والمسافات**: استخدم توكنز `:root` (`--e1/--e2/--e3` للظلال،
  `--r-sm/--r-md/--r-lg` للزوايا، `--t-fast/--t-med` و`--ease` للحركة).

## النشر

- **الواجهة**: أي استضافة استاتيك (GitHub Pages مثلًا) — ارفع `index.html` و`sw.js` و`manifest.json` و`img/` والأيقونات.
- **الباك إند**: انسخ محتوى `apps_script.gs` بالكامل إلى محرر Apps Script، احفظ، ثم انشر
  **إصدار جديد على نفس عملية النشر** (مش نشر جديد) — التفاصيل تحت.

> ⚠️ **مهم: متعملش «عملية نشر جديدة» (New deployment).**
> رابط الـ Web App مكتوب ثابت في `index.html` (`APPS_SCRIPT_URL`). «عملية نشر جديدة»
> بتدّي **رابط جديد**، والتطبيق هيفضل بيكلّم النسخة القديمة — فأي تعديل في الباك إند
> مش هيوصل، والتطبيق يبان كإنه شغّال بس بكود قديم.
>
> **الطريقة الصح (بتحافظ على نفس الرابط):**
> 1. **نشر** (Deploy) ← **إدارة عمليات النشر** (Manage deployments)
> 2. اضغط أيقونة **القلم ✏️** جنب عملية النشر الموجودة
> 3. **الإصدار** (Version) ← اختار **إصدار جديد** (New version)
> 4. **نشر** (Deploy)
>
> لو غيّرت الرابط عن قصد لأي سبب، لازم تعدّل `APPS_SCRIPT_URL` في `index.html`
> وترفع الملف تاني.
- بعد أي تعديل في `index.html`، لازم تزوّد `CACHE_VERSION` في `sw.js` **و**`APP_BUILD`
  في `index.html` (الاتنين لازم يبقوا نفس الرقم) عشان المستخدمين ياخدوا النسخة الجديدة.
- **لو غيّرت صورة أو أيقونة** (حاجة جوه `img/` أو `icon-*.png`): زوّد كمان `ASSET_VERSION`
  في `sw.js`. الصور في كاش دايم منفصل مابيتمسحش مع تحديثات التطبيق العادية — وده
  اللي بيمنع إن كل تحديث ينزّل الـ370 كيلوبايت صور من أول وجديد على كل جهاز.

## كلمة سر شاشة المصنع

> ⚠️ **خطوة إلزامية قبل أي نشر.** كلمة السر مابقتش مكتوبة في `apps_script.gs`.
> كانت مكتوبة صريحة، والملف ده في مستودع GitHub **عام** — يعني أي حد يفتح الرابط
> كان يشوفها. لو مظبطتهاش، شاشة المصنع هترفض الدخول وهتقول لك تظبطها.

**إزاي تظبطها (مرة واحدة بس):**

1. افتح محرر Apps Script بتاع المشروع
2. من الشمال: ⚙️ **Project Settings**
3. انزل لـ **Script Properties** → **Add script property**
4. `Property` = `ADMIN_PW` — `Value` = كلمة السر اللي تختارها
5. **احفظ** (Ctrl+S)، وبعدين انشر **إصدار جديد على نفس عملية النشر** (شوف تحذير النشر فوق — مش «عملية نشر جديدة»)

Script Properties بتتخزّن في إعدادات المشروع نفسه — مش في أي ملف، ومش بتترفع على GitHub.

**لو حبيت تغيّرها بعدين:** عدّل قيمة الـ property وبس. مش محتاج تعيد النشر ولا تعدّل أي كود.

### الحماية من التخمين

`checkAdminPw_` بتشتغل بطبقتين:

- **طبقة الجهاز** — ٥ محاولات غلط من نفس الجهاز تقفل **الجهاز ده بس** ١٥ دقيقة.
- **طبقة عامة** — مافيش قفل نهائي أبدًا، بس تأخير بيكبر مع المحاولات الغلط (لحد ٨ ثواني).

الطريقة دي بتمنع حاجتين مع بعض: التخمين بيبقى بطيء جدًا، ومحدش يقدر يقفل الشاشة
على موظفي المصنع بمحاولات غلط متعمّدة (النسخة القديمة كان القفل فيها عام — أي حد
يعمل ١٥ محاولة غلط كان بيقفل الشاشة على الكل).

التطبيق بيبعت معرّف جهاز (`dev`) مع نداءات شاشة المصنع بس. المعرّف ده **مش وسيلة تحقق**
ومش سر — مجرد تفرقة بين الأجهزة عشان القفل يبقى موضعي.
