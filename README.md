# ELKORASHI DOORS — طلبات أبواب WPC

تطبيق PWA لطلب أبواب WPC (القرشي)، بدون أي أدوات بناء — فتح `index.html` مباشرة كافٍ.

## بنية المشروع

| الملف/المجلد     | الوظيفة |
|---|---|
| `index.html`     | التطبيق بالكامل: HTML + CSS + JS (المصدر الرسمي الوحيد — لا يوجد ملف بناء ناتج) |
| `sw.js`          | Service Worker: الكاش والتحديث التلقائي (لازم ترفع رقم `CACHE_VERSION` مع كل ديبلوي) |
| `manifest.json`  | بيانات تثبيت الـ PWA |
| `img/`           | صور الأبواب واللوجو (منفصلة عن الكود، بتتكاش بمعرفة `sw.js`) |
| `icon-192.png`, `icon-512.png` | أيقونات التثبيت |
| `apps_script.gs` | كود الباك إند (Google Apps Script) — الصق نسخة منه في محرر Apps Script المربوط بشيت `WPC_Door_Orders_2026` عند أي تعديل، وأعد نشر الـ Web App |

## المكتبات الخارجية

المكتبات التقيلة **مش** بتتحمّل مع فتح التطبيق — بتتحمّل أول مرة تتطلب فيها بس، عن طريق
`ensureLib_()` / `needLibs_()` في `index.html`:

| المكتبة | بتستخدم في |
|---|---|
| `html2canvas` | رسم مستند الطلب/التقرير على canvas قبل تحويله PDF أو صورة |
| `jsPDF` | تحويل الـ canvas لملف PDF بصفحات A4 |
| `ExcelJS` | كل ملفات الإكسيل (التصدير العادي وتصدير المصنع) |

لو محتاج تضيف مكتبة جديدة: زوّدها في `LIB_URLS` و`LIB_READY`، وناديها بـ
`if(!await needLibs_('اسمها')) return;` قبل أي استخدام لها. المكتبات بتتخزّن في كاش منفصل
اسمه `elkorashy-libs-v1` مابيتمسحش مع تحديثات التطبيق العادية.

> ملاحظة: مكتبة `xlsx` اتشالت — كانت مكرّرة مع `ExcelJS` وبتعمل نفس الشغل.

## قواعد لازم تتراعى وانت بتعدّل

- **الرسم**: `render()` بيتجمّع في إطار رسم واحد. لو محتاج رسم فوري (زي أول تشغيل)
  نادي `renderNow()`. الفوكس ومكان المؤشر في الخانات ومكان التمرير بيترجعوا تلقائي
  بعد كل رسم — فمافيش داعي تتجنّب `render()` وانت بتكتب في خانة.
- **الأيقونات**: استخدم `ico('اسم')` من قاموس `ICONS` — مافيش إيموجي في واجهة التطبيق،
  لأن شكله بيختلف من موبايل للتاني وبيضرب الهوية البصرية.
- **الألوان والمسافات**: استخدم توكنز `:root` (`--e1/--e2/--e3` للظلال،
  `--r-sm/--r-md/--r-lg` للزوايا، `--t-fast/--t-med` و`--ease` للحركة).

## النشر

- **الواجهة**: أي استضافة استاتيك (GitHub Pages مثلًا) — ارفع `index.html` و`sw.js` و`manifest.json` و`img/` والأيقونات.
- **الباك إند**: انسخ محتوى `apps_script.gs` بالكامل إلى محرر Apps Script، ثم Deploy → New deployment كل مرة تتعدل فيها.
- بعد أي تعديل في `index.html` أو أي أصل يتكاش، لازم تزوّد `CACHE_VERSION` في `sw.js`
  **و**`APP_BUILD` في `index.html` (الاتنين لازم يبقوا نفس الرقم) عشان المستخدمين ياخدوا النسخة الجديدة.

## كلمة سر شاشة المصنع

قابلة للتغيير من `ADMIN_PW` في `apps_script.gs`. محمية من التخمين عبر `checkAdminPw_` (تأخير متزايد + قفل مؤقت بعد محاولات فاشلة كتير).
