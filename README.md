# ELKORASHI DOORS — طلبات أبواب WPC

تطبيق PWA لطلب أبواب WPC (القرشي)، بدون أي أدوات بناء — فتح `index.html` مباشرة كافٍ.

## بنية المشروع

| الملف/المجلد     | الوظيفة |
|---|---|
| `index.html`     | التطبيق بالكامل: HTML + CSS + JS (المصدر الرسمي الوحيد — لا يوجد ملف بناء ناتج) |
| `sw.js`          | Service Worker: الكاش والتحديث التلقائي (لازم ترفع رقم `CACHE_VERSION` مع كل ديبلوي) |
| `manifest.json`  | بيانات تثبيت الـ PWA |
| `img/`           | صور الأبواب واللوجو (منفصلة عن الكود، بتتكاش بمعرفة `sw.js`) |
| `icon-192.png`, `icon-512.png` | أيقونات التثبيت |
| `apps_script.gs` | كود الباك إند (Google Apps Script) — الصق نسخة منه في محرر Apps Script المربوط بشيت `WPC_Door_Orders_2026` عند أي تعديل، وأعد نشر الـ Web App |

## النشر

- **الواجهة**: أي استضافة استاتيك (GitHub Pages مثلًا) — ارفع `index.html` و`sw.js` و`manifest.json` و`img/` والأيقونات.
- **الباك إند**: انسخ محتوى `apps_script.gs` بالكامل إلى محرر Apps Script، ثم Deploy → New deployment كل مرة تتعدل فيها.
- بعد أي تعديل في `index.html` أو أي أصل يتكاش، لازم تزوّد `CACHE_VERSION` في `sw.js` عشان المستخدمين ياخدوا النسخة الجديدة.

## كلمة سر شاشة المصنع

قابلة للتغيير من `ADMIN_PW` في `apps_script.gs`. محمية من التخمين عبر `checkAdminPw_` (تأخير متزايد + قفل مؤقت بعد محاولات فاشلة كتير).
